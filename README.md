# 🛒 Blinkit Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing Blinkit's grocery delivery data to understand sales performance, customer behavior, product pricing, discounts, and delivery operations. The goal is to transform raw data into meaningful business insights using data analytics tools.

## 🎯 Objectives

- Analyze order and product performance.
- Understand customer purchasing behavior.
- Explore product prices, MRP, and discounts.
- Evaluate delivery performance and delays.
- Build an interactive Power BI dashboard for business insights.

## 🛠️ Tools & Technologies

- **Python** — Data analysis and preprocessing
- **Pandas** — Data cleaning and manipulation
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Exploratory Data Analysis (EDA)
- **SQL** — Business queries and analysis
- **Microsoft Power BI** — Interactive dashboard and reporting

## 📂 Dataset Structure

The project uses four related datasets:

| Dataset | Description |
|---|---|
| `blinkit_products.csv` | Product details, categories, brands, prices, and stock levels |
| `blinkit_customers.csv` | Customer information and segments |
| `blinkit_orders.csv` | Order details, payment methods, and delivery information |
| `blinkit_order_items.csv` | Products and quantities associated with orders |

## 🔄 Project Workflow

1. **Data Cleaning:** Handled missing values, duplicates, and data types.
2. **Feature Engineering:** Created useful columns for analysis, such as discounts and delivery metrics.
3. **Exploratory Data Analysis:** Used Python charts to identify trends and patterns.
4. **SQL Analysis:** Analyzed business metrics using SQL queries.
5. **Power BI Dashboard:** Designed interactive visualizations and KPI cards.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `Blinkit_EDA.ipynb` in Jupyter Notebook.
3. Place the dataset CSV files in the appropriate project folder.
4. Run the notebook cells to explore the data.
5. Open `Blinkit_Dashboard.pbix` using Microsoft Power BI Desktop.
